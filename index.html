01 / Rationale & Positioning

Moving from Biological Literacy to Computational Capability

Physiology graduates possess deep training in systems thinking, homeostasis, experimental measurement, and human function. Yet most lack structured pathways to translate that scientific foundation into Python data workflows, signal analytics, and biomedical AI applications.

PILLAR 01

Mechanism-First AI Literacy

Understand how machine learning models interpret physiological variables—and where algorithmic predictions fail without biological context and data validation.

PILLAR 02

Hands-On Physiological Datasets

Work directly with structured clinical records, electrocardiogram (ECG) waveforms, heart-rate variability (HRV) series, and electroencephalogram (EEG) features.

PILLAR 03

Demonstrable Portfolio Proof

Conclude the three-day cohort with a small, documented biomedical data application that serves as tangible evidence for research, internships, or industry roles.

02 / Proposed Curriculum Architecture

Three-Day Specialist Progression

DAY 01 • FOUNDATIONS MODULE 01

Understanding AI in Physiological Science

  • — Foundations of artificial intelligence and machine learning in life sciences.
  • — The intersection of systems physiology, data science, and clinical decision tools.
  • — Anatomy of physiological datasets and time-series biomedical signals.
  • — Responsible AI, bias, validation rigour, and limits of algorithmic interpretation.
Participant Outcome

Clear conceptual command of biomedical AI possibilities, data hygiene, and ethical boundaries.

DAY 02 • ANALYTICS MODULE 02

Computational Physiology & Biomedical Data

  • — Practical introduction to Python notebooks for biomedical data workflows.
  • — Cleaning, structuring, and inspecting multi-variable physiological datasets.
  • — Hands-on ECG rhythm, HRV feature extraction, and EEG signal exploration.
  • — Scientific visualisation, statistical summaries, and baseline predictive models.
Participant Outcome

Ability to load, analyse, and visualise a structured physiological dataset in Python.

DAY 03 • SYNTHESIS MODULE 03

Building Intelligent Biomedical Applications

  • — Developing a guided mini AI-enabled physiological analysis application.
  • — Translating physiological research questions into reproducible computational workflows.
  • — Interpreting model outputs and communicating findings to scientific audiences.
  • — Structuring a professional portfolio and mapping next-step research pathways.
Participant Outcome

A completed, demonstrable mini-project ready for academic or career portfolios.

const SHEET_NAME = 'EOI_Submissions';
const CAREER_PORTAL_URL = 'https://taupe-arithmetic-81e5a2.netlify.app/';
const INSTITUTE_URL = 'https://www.fsi-aibr.org/';
const KEYNOTE_PDF_URL = 'https://www.fsi-aibr.org/assets/The-Physiologist-Reimagined-Daniel-Onimisi.pdf';

function doPost(e) {
  try {
    const data = JSON.parse(e.postData.contents);
    const ss = SpreadsheetApp.getActiveSpreadsheet();
    let sheet = ss.getSheetByName(SHEET_NAME);

    if (!sheet) {
      sheet = ss.insertSheet(SHEET_NAME);
      sheet.appendRow([
        'Reference ID',
        'Timestamp (WAT)',
        'Full Name',
        'Email',
        'Phone / WhatsApp',
        'Institution',
        'Academic Standing',
        'SPAN Status',
        'Applicable Fee Tier',
        'Primary Interest Track',
        'Prior Coding Experience',
        'Motivation Note'
      ]);
      sheet.getRange(1, 1, 1, 12).setFontWeight('bold');
    }

    // Deduplicate by email address
    const existingData = sheet.getDataRange().getValues();
    const submittedEmail = String(data.email || '').trim().toLowerCase();
    for (let i = 1; i < existingData.length; i++) {
      if (String(existingData[i][3] || '').trim().toLowerCase() === submittedEmail) {
        return ContentService.createTextOutput(
          JSON.stringify({ status: 'duplicate', referenceId: existingData[i][0] })
        ).setMimeType(ContentService.MimeType.JSON);
      }
    }

    sheet.appendRow([
      data.referenceId,
      new Date(),
      data.fullName,
      submittedEmail,
      data.phone,
      data.institution,
      data.academicStanding,
      data.spanStatus,
      data.feeTier || '',
      data.interestTrack,
      data.priorExperience,
      data.learningGoal || ''
    ]);

    sendInstitutionalConfirmationEmail(data);

    return ContentService.createTextOutput(
      JSON.stringify({ status: 'success', referenceId: data.referenceId })
    ).setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(
      JSON.stringify({ status: 'error', message: err.toString() })
    ).setMimeType(ContentService.MimeType.JSON);
  }
}
